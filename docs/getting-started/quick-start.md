# Quick start

## Launch BlueP

```bash
uv run bluep
```

## Create a new project

1. Click **Project → New** in the menu bar, or press `Ctrl+N`.
2. Choose a directory for your project.
3. The project opens with an empty class diagram.

## Add a class

1. Click **Class → New** or right-click on the diagram and select **New Class**.
2. Enter a class name (e.g. `Counter`).
3. Choose a kind: Concrete, Abstract, Interface, or Dataclass.
4. The class appears as a box in the diagram.

## Write code

1. Double-click the class box (or right-click → **Open Editor**).
2. The code editor opens in a tab with syntax highlighting, autocomplete,
   and bracket auto-closing.
3. Write your class. Press `Ctrl+S` to save and compile.

## Instantiate on the bench

1. Right-click the class box → **Instantiate**.
2. Provide constructor arguments if needed.
3. The object appears on the bench at the bottom of the window.

## Call methods

1. Right-click a bench object → **Call Method**.
2. Select a method from the list.
3. Provide arguments if needed.
4. The return value appears in the result field.

## Use the code pad

1. Click the **Code Pad** tab at the bottom.
2. Type a Python expression and press Enter.
3. The result is displayed inline.
